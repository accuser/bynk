changelog: Resolves #1486 (the `verbatim_sites` capstone, closing the `the-typescript-tree` track's own `emitter::emit_project`/`emit_test_module`/`emit_integration_module` gap). All three orchestrator functions now return a real `bynk_ts::TsProgram`/`Vec<TsStmt>`, printed once at the write boundary via `bynk_ts::print`/the new `bynk_ts::print_multi_source` (which builds the source map directly from each statement's own `span`/`nested_map`, rather than the function hand-driving a `SourceMapBuilder` through `print_stmt_and_merge`), instead of returning a pre-rendered `String` wrapped in one opaque `TsStmt::verbatim`. The three real call sites (`project.rs`'s `emit_unit`, `project/tests_emit.rs`'s `process_tests`/`process_integration_tests`) drop their own `Verbatim`-wrapping and consume the tree directly. `verbatim_sites` (gated probe) drops from 5 to its argued floor of **2** (`project.rs:2478`/`:2507` — an adapter binding's own foreign, user-authored TS content and the committed `runtime.ts` build artifact, both already argued permanent by ADR 0399, unchanged by this capstone); `ts_writes` drops 817 → 808. Fixes a real pre-existing byte-for-byte regression this same conversion uncovered (`919_json_decode_named_record_in_test_case`/`920_json_encode_only_named_record_in_test_case`) — `emit_test_module`'s own json-codec-closure helpers had already been adapted (in an earlier slice) to rely on the printer's automatic top-level blank-line policy, but the still-`String`-based caller printed them through the pre-automatic-policy `extend_printed_at` path, silently dropping one blank line the real fixtures expect. Also retires `emitter::inject_runtime_imports`/`missing_bindings` (the post-print text-splice mechanism for folding a codec group's extra runtime-import bindings into an already-rendered import line), now dead — both converted callers build the runtime-import statement's own `names: Vec<String>` directly (deferred to the end of each function, once `RuntimeUse` is fully populated, mirroring `emit_project`'s own prior `write_header` reordering) through a `Vec`-level dedup helper (`project/tests_emit.rs`'s own `append_missing_bindings`, the same shape `emitter/workers.rs`/`emitter/workers_entry.rs` already carry their own copies of), rather than splicing into text.
