changelog: "A context split across files builds and runs on the workers target (#1820). Each file used to be written to the Worker's `handlers.ts` in turn, each overwriting the last, so the Worker kept only one file's declarations and failed `tsc`. Each file is now its own module under `workers/<context>/handlers/`, and `handlers.ts` re-exports them, defining one `__resetAgents` over every file's agents and re-exporting from one module each boundary codec two files both emit (TS2308). An agent's Durable Object rebuilds its `given` providers from that deeper module, reaching its own context's through `handlers.ts`; a handler's `deps.env` names every agent of the context, not only its file's; and a file constructing only a sibling's agents imports the namespace type it names. On both targets, a file now imports, as a type, a capability a sibling file declares, and the capabilities of a sibling's agents it calls are part of its `deps` (and, on bundle, its context's deps type), where the output failed `tsc` (TS2304, TS2503, TS2345). On bundle, the context's barrel (`<context>.ts`) is part of every build, not only a test build: the composition root imports it (TS2307)"
