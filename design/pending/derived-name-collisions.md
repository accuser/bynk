changelog: Names the compiler generates from your declarations no longer collide with names you declare yourself. A capability's token, a provider's binding, a context's surface factory and deps interface, a test's deps and harness factories, and a message bundle's tables are now `__`-prefixed (`__ClockToken`, `__SystemClockProvider`, `__makeSurface`, `__DemoClockDeps`, `__makeTestDeps`, `__messagesLocales`), and a bundle's generated `render` reaches `LocaleTag`, `Message`, `MessageArg` and `renderArg` under private aliases, so a `type ClockToken`, a `fn makeSurface` or a bundle's own `type Message` now compiles. An agent's `<Agent>State` is a name its handlers can write, so a type of that name beside the agent is now `bynk.agent.state_name_conflict` instead of being silently replaced (#1697)
